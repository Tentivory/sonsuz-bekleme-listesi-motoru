# Sonsuz Bekleme Listesi Motoru

## Devrim Niteliğinde Bir İcat

Bu proje, insanlığın en büyük başarısıdır: **Hiçbir şeyin asla sırasının gelmemesi**.

Hastane randevusu, banka sırası, otobüs, devlet dairesi, pizza siparişi... Hepsi artık bu motorla sonsuza kadar bekleyebilir. Siz bekleyin, motor bekletsin.

## Neden Bu Proje?

Çünkü beklemek bir sanattır. Bu motor o sanatı profesyonel seviyeye taşır. Sıra numaranız "çok yakında" der ama asla gelmez.

## Kullanım

```bash
python bekle.py
```

Program sizi beklemeye alır ve bir daha bırakmaz. Ctrl+C ile kurtulabilirsiniz ama sonra pişman olursunuz.

## Özellikler

- Rastgele "biraz daha bekleyin" mesajları
- Sıra numarası asla düşmez
- Tahmini bekleme süresi: sonsuz
- Müşteri memnuniyeti: %0 (bu da bir özellik)
